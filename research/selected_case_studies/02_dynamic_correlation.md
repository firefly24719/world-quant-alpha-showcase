# Correlation and submission order

The submitted Alpha set changes over time. Each official Self-Correlation result is therefore recorded with the check time and the ACTIVE snapshot. A historical pass is rechecked after a submission changes that set.

One observed sequence showed why direction matters. After the first candidate was submitted, the second candidate's reported correlation rose to approximately **0.83**. The user confirmed that it was submitted through the platform's Sharpe-improvement exception. This observation supports considering both pairwise overlap and relative Sharpe when evaluating an order.

Local date-aligned daily PnL correlations can forecast possible conflicts between unsubmitted candidates. They are proxies, and a locally planned sequence is a conditional research scenario rather than a guarantee of future official passes.
