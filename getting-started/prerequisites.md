# Prerequisites

- A working BRAIN account with access to Simulation and Results.
- A browser and an AI assistant able to read the upstream links or installed skills.
- A private place to record expressions, settings and results.
- Your account's available region, universe, delay, fields, operators and applicable competition checks, confirmed in BRAIN.

The manual path needs no Python or API credential. An upstream skill installation may need Git or Node.js. The gold-week optional Python scripts require Python 3, requests and numpy. Keep passwords, cookies and API keys out of prompts and public repositories.
