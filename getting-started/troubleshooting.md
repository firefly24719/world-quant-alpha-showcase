# Troubleshooting

| Problem | Action |
|---|---|
| Skill not found | Confirm SKILL.md and references are in your client's supported folder and reload. Alternatively ask your assistant to read the upstream links. |
| Field or operator unavailable | Search BRAIN with your region, universe and delay. Verify a substitute's semantics and units. |
| Expression error or unit warning | Read the exact platform message and check arguments, field units and missing values before retrying. |
| Simulation pending or limit reached | Wait for the platform and follow the displayed limit; avoid duplicate launches. |
| Sharpe or Fitness fails | Examine annual behavior, turnover and the hypothesis. Test a baseline or a controlled change. |
| Sub-universe or concentration fails | Inspect coverage, missingness and weight distribution if available. Keep the cause provisional. |
| Self-Correlation pending or fails | Check the platform result and record time and ACTIVE context. Recheck after an actual submission changes that context. |
| Missing annual values or checks | Record unknown or pending and analyze only available evidence. |

Some upstream scripts authenticate, simulate or submit. Inspect any code before running it.
